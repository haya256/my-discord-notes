# 通知を減らす

## 要点

- 通知は「Discord全体」「サーバー単位」「チャンネル単位」の順に細かく設定できる
- まずは**サーバー単位で「@mentionsのみ」+「@everyoneと@hereの通知を行わない」**にするのが手軽
- 見たいチャンネルだけ通知したいときは、チャンネル単位で上書きする

## 手順(PC)

### サーバー全体を静かにする

1. 左端のサーバーアイコンを右クリック
2. 「通知設定」にマウスを乗せて、サブメニューを開く
3. 「@mentionsのみ」を選ぶ(ほかに「すべてのメッセージ」「通知しない」がある)
4. 必要なら「@everyoneと@hereの通知を行わない」にチェックを入れる
5. 完全に止めたいときは、右クリックメニューの「サーバーを通知オフ」

### 特定のチャンネルだけ変える

1. チャンネル名を右クリック
2. 「チャンネルを通知オフ」、または通知設定でそのチャンネルだけ別の設定にする

### Discord全体の通知を止める

1. 左下の、マイク・ヘッドホンのアイコンの横にある歯車「ユーザー設定」
2. 左メニューの「通知」→「概要」
3. 「デスクトップ通知を有効にする」をオフにする
4. 必要なら「タスクバーの点滅を有効化」もオフ。音を止めたいときは、同じ画面の「サウンド」の各項目をオフにする

## メモ

- 新しく参加したサーバーは、そのサーバーの既定の通知設定から始まる。参加したら最初に自分の設定に変える
- サーバー管理者は、サーバーの「既定の通知設定」を「@mentionsのみ」にしておくと参加者に優しい
