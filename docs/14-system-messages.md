# 参加メッセージ(システムメッセージ)の設定

## 要点

- 新しく人が参加したときの「〇〇が来た!」のような自動メッセージは、Discord本体の**システムメッセージ**。決まった文の中からランダムに1つが投稿され、**文は自分で書きかえられない**
- 設定は「サーバー設定」→「**Engagement(エンゲージメント)**」の「システムメッセージ」にある
- 「システムのメッセージチャンネル」を「**システムのメッセージはありません**」にしておけば、システムメッセージは1つも投稿されない
- 参加メッセージや、スタンプでの返事をうながす表示だけを止めることもできる

## システムメッセージとは

サーバーで何かが起きたときに、Discordが自動で投稿するメッセージ。主に次の4種類がある。

| 種類 | 内容 |
|---|---|
| 参加メッセージ | 人が参加したときに、「〇〇が来た!」のような文をランダムに投稿する |
| スタンプでの返事の促し | 参加メッセージの下に、スタンプ(ステッカー)で「ようこそ」と返事をするためのボタンを出す。押すと、手を振るような動くスタンプが投稿される |
| ブーストのお知らせ | 誰かがサーバーをブーストしたときに投稿する([12-server-boost.md](12-server-boost.md) を参照) |
| サーバー設定のヒント | サーバーの管理者向けに、設定のヒントを投稿する |

- 参加メッセージの文は明るく砕けた調子のものが多く、動くスタンプも出るので、Discordに慣れていない人が多いサーバーでは**にぎやかすぎる**と感じることがある

## 設定の場所(PC)

1. サーバー名を押して「サーバー設定」を開く
2. 左メニューの「**Engagement(エンゲージメント)**」を開く
3. 「**システムメッセージ**」の項目に、次の4つのスイッチと、投稿先のチャンネルの設定がある

| 画面の表記 | 内容 |
|---|---|
| 「このサーバーに参加した人がいたら、ウェルカムメッセージをランダムに送信します。」 | 参加メッセージ |
| 「ウェルカムメッセージにスタンプで返信するようメンバーに促します。」 | スタンプでの返事の促し |
| 「このサーバーをブーストした人がいたら、メッセージを送信します。」 | ブーストのお知らせ |
| 「サーバー設定に役立つヒントをお寄せください。」 | サーバー設定のヒント |
| 「システムのメッセージチャンネル」 | システムメッセージを投稿するチャンネル。「システムのメッセージはありません」も選べる |

- 画面の表記は 2026-11-15 に実機(PC版)で確認した
- 以前は「概要」(英語版は Overview)の中にあった。ネット上の古い記事には「概要」と書かれていることがある

## やりたいこと別の設定

| やりたいこと | 設定 |
|---|---|
| システムメッセージを一切出したくない | 「システムのメッセージチャンネル」を「システムのメッセージはありません」にする |
| ブーストのお知らせは出したいが、参加メッセージとスタンプは出したくない | チャンネルを選んでから、上の2つのスイッチ(参加メッセージ、スタンプでの返事の促し)をオフにする |
| 参加メッセージは出したいが、スタンプはいらない | チャンネルを選んでから、2つ目のスイッチ(スタンプでの返事の促し)だけをオフにする |
| 参加メッセージを目立たない所に出したい | 参加ログ用のチャンネルを作って、そこを投稿先にする。ふつうのメンバーは書き込めないようにしておく |

## 落ち着いたあいさつにしたいとき

Discord本体の参加メッセージは文を変えられないので、次のような方法を使う。

- **自分で書いた案内を固定しておく**:参加メッセージはオフにして、ルールや案内のチャンネルに「ようこそ。まずはこのチャンネルを読んでください」のような文を書いておく。メッセージをピン留めしておくと、あとから見つけやすい
- **コミュニティ機能のオンボーディングを使う**:コミュニティ機能をオンにしているサーバーなら、参加した人に案内や質問を見せられる([11-community.md](11-community.md) を参照)
- **Botを使う**:参加した人に、自分で書いた文を自動で投稿してくれるBotがある。ただし、BotはDiscordの公式機能ではない外部サービス(この記事では扱わない)。Botであいさつするなら、二重にあいさつしないよう、Discord本体の参加メッセージはオフにする

## メモ

- **チャンネルが「システムのメッセージはありません」のとき、4つのスイッチは薄い色で表示され、操作できなかった**(2026-11-15 実機で確認。スイッチはオンの見た目のままだった)。投稿先がないので、スイッチの値に関係なく何も投稿されないと考えられる
- チャンネルを選んだあとにスイッチが操作できるようになるか、選んだ直後からスイッチの値(オン)がそのまま効くかは、**未確認**。チャンネルを選んだら、すぐにスイッチを確認する
- 参加メッセージの文がランダムで、書きかえられないこと、スタンプのボタンを押すと手を振るようなスタンプが投稿されることは、ネットの情報による(未確認)
- Discordの公式フォーラムには、「スタンプでの返事の促しを止めたい」という要望が以前から出ていた。今はスイッチで止められるようになっている(上の画面の表記を参照)
