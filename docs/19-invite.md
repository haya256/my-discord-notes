# サーバーに招待する

## 要点

- サーバーのアイコンを右クリックして「**サーバーに招待**」を選ぶと、招待の画面が開く(実機で確認)
- 招待のしかたは2つ。**フレンドを選んで「招待」を押す**(相手にDMで届く)か、**招待リンクをコピーして渡す**か
- 招待された人が最初に入るチャンネルは、**招待の画面を開いたときに見ていたチャンネル**になる。チャンネルを右クリックして「**チャンネルに招待**」からも招待できる(実機で確認)
- 招待リンクには**期限がある**。実機では「招待リンクは 30 日後に期限切れになります。」と表示された。「招待リンクを編集する」から変えられる
- **管理者でなくても招待できる**ことがある。招待できるかどうかは、ロールの「招待を作成」の権限で決まる(未確認)

## 手順

### 招待の画面を開く

1. 画面の左端のサーバー一覧で、招待したいサーバーのアイコンを**右クリック**する
2. メニューの上の方にある「**サーバーに招待**」を選ぶ

(実機で確認。メニューには「サーバーに招待」のほかに「サーバーを通知オフ」「通知設定」「プライバシー設定」「サーバーから脱退」などが並ぶ)

### フレンドを選んで招待する

招待の画面は、次のようになっている(実機で確認)。

| 場所 | 表示 |
|---|---|
| いちばん上 | 「フレンドを(サーバー名)に招待する」 |
| その下 | 「受信者は (チャンネル名) にアクセスします」(招待された人が最初に入るチャンネル) |
| 真ん中 | 検索の欄と、フレンドの一覧。名前の横に「**招待**」のボタン |
| いちばん下 | 「または、フレンドにサーバー招待リンクを送る。」と、招待リンク・「コピー」のボタン |
| その下 | 「招待リンクは 30 日後に期限切れになります。」と「招待リンクを編集する」 |

1. 検索の欄にフレンドの名前を少し入れると、一覧がしぼられる
2. 招待したい人の横の「**招待**」を押す
3. 相手には、招待がDMで届く(未確認。ふつうはDMに招待のカードが出る)

- 一覧に出るのは**フレンドだけ**。フレンドでない人には、下の招待リンクを渡す

### 最初に入るチャンネルを変える

招待の画面の「受信者は (チャンネル名) にアクセスします」のチャンネルは、**招待の画面を開いたときに見ていたチャンネル**になる(実機で確認)。変えるには、次のどちらかにする。

- 入ってほしいチャンネルを開いてから、サーバーのアイコンを右クリックして「サーバーに招待」を選ぶ(実機で確認)
- チャンネル一覧で、入ってほしいチャンネルを**右クリック**して「**チャンネルに招待**」を選ぶ(実機で確認。メニューには「お気に入りに追加」「チャンネルを上部にピン留め」「リンクをコピー」「チャンネルの編集」なども並ぶ)

- 招待された人が見られないチャンネル(権限で隠しているチャンネル)を選んでも、その人は中を見られない(未確認)
- 「招待リンクを編集する」では、チャンネルは選べないと思われる(未確認)
- チャンネル名にマウスを乗せると出る、人の形のアイコンからも招待できるという情報もある(未確認)

### 招待リンクを渡す

1. 招待の画面のいちばん下の「**コピー**」を押す
2. コピーしたリンク(`https://discord.gg/…`)を、DMやメール、SNSなどで相手に送る

### 招待リンクの期限などを変える

1. 招待の画面のいちばん下の「**招待リンクを編集する**」を押す
2. 期限(何日後に使えなくなるか)や、使える回数を選ぶ(中身は未確認)

- 期限があるリンクは、期限が来ると使えなくなる。たとえば会員向けのページなど、**あとから入る人のために置いておくリンク**は、期限を「なし」にしておく([09-membership-services.md](09-membership-services.md))

## 管理者でなくても招待できるのはなぜ?

ここは一般的な知識からまとめた。実機では確認していない。

- 招待できるかどうかは、ロールの「**招待を作成**」(英語版は Create Invite)の権限で決まる
- 新しく作ったサーバーでは、ふつう **@everyone でこの権限がオン**になっている。だから、管理者でないメンバーも招待できる
- ロールの権限は足し算で、ロールのない人は @everyone の権限で決まる。くわしくは [13-roles.md](13-roles.md)

### メンバーに招待させたくないとき(管理者)

1. 「サーバー設定」→「ロール」→ @everyone の権限で、「招待を作成」をオフにする
2. 招待してよい人のロール(例:モデレーター)では、オンにしておく

- ほかのロールやチャンネルごとの上書きで許可されていると、その人は招待できる([13-roles.md](13-roles.md))
- 荒らしがたくさん入ってきたときに、招待を**一時的に止める**方法は [10-raid-protection.md](10-raid-protection.md)

## ほかに知っておくとよいこと

- コミュニティ機能をオンにしても、サーバーは公開されない。今までどおり、招待リンクを知っている人だけが入れる([11-community.md](11-community.md))
- サーバーブーストのレベル3では、`discord.gg/好きな名前` のような**カスタム招待リンク**を作れる([12-server-boost.md](12-server-boost.md))
- Botをサーバーに入れるのは、この記事の招待とは別のしくみ([04-webhooks.md](04-webhooks.md)、[17-apps.md](17-apps.md))
