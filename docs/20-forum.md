# フォーラムチャンネル

## 要点

- フォーラムチャンネルは、**話題ごとに「投稿」を立てて、その中で話す**チャンネル。掲示板のようなもの。ふつうのテキストチャンネルのように、話題がどんどん流れて埋もれることがない
- 投稿は、**タイトル・最初のメッセージ・タグ**でできている。中身のしくみはスレッドと同じ([21-threads.md](21-threads.md))
- 動きとしては「**1投稿ごとに、小さなチャンネルが自動でできる**」のに近い(下の「テキストチャンネルとのちがい」)
- 作れるのは、**コミュニティ機能をオンにしたサーバーだけ**([11-community.md](11-community.md))
- 管理者は、「投稿ガイドライン」(どんな投稿をしてほしいか)と「タグ」(投稿の分類)を決めておくと使いやすくなる
- 質問・サポート、要望、作品の紹介、募集など、**1つの話題が長く続くもの**に向く

この記事は、ネットの情報からまとめたもの。実機では確認していない。日本語の画面の名前は、非公式の日本語の解説からとったもので、今の画面と違うことがある。

## テキストチャンネルとのちがい

| | テキストチャンネル | フォーラムチャンネル |
|---|---|---|
| 話し方 | 1つの流れに、みんなが続けて書く | 話題ごとに投稿を立て、その中で話す |
| 古い話題 | 上に流れて見つけにくい | 投稿の一覧に残る。検索やタグでしぼれる |
| 向いているもの | 雑談、その場のやりとり | 質問、要望、作品、募集、長く続く話題 |
| 条件 | どのサーバーでも作れる | コミュニティ機能が必要 |

- 今あるテキストチャンネルを、フォーラムに**変えることはできない**(非公式の情報)。新しくフォーラムを作って、そちらに移す

### 「1投稿ごとに小さなチャンネルができる」と考えるとわかりやすい

動きとしては、**投稿を1つ立てるたびに、フォーラムの下に小さなチャンネルが1つできる**のに近い。しくみもそのとおりで、投稿はスレッドでできていて、Discordの中(開発者向けのAPI)ではスレッドもチャンネルの一種として扱われる。

ただし、ふつうのチャンネルとは次の点がちがう。

| | ふつうのチャンネル | フォーラムの投稿 |
|---|---|---|
| 作れる人 | 「チャンネルの管理」の権限がある人(管理者など) | メンバーが自分で立てられる |
| 出てくる場所 | 左のチャンネル一覧 | フォーラムの中の投稿一覧(左の一覧は増えない) |
| 権限 | チャンネルごとに決められる | フォーラムの権限をそのまま受けつぐ。投稿ごとには決められない |
| 話されなくなったら | ずっと同じ場所にある | 決めた時間がたつと「古い投稿」の方に移る。書きこむとまた上に出る |
| 通知 | チャンネルの通知設定で決まる | ふつうはフォローしている投稿だけ |
| 分け方 | カテゴリー | タグ |

つまり、**メンバーが自分で立てられて、権限はまとめて管理できる、軽いチャンネル**。話題ごとにチャンネルを作るとチャンネルが増えすぎる使い方(質問を1件ずつ、作品を1つずつ、など)に向く。

- 「投稿ごとに権限を決められない」「投稿は左の一覧に出ない」は、スレッドのしくみからの説明で、実機では未確認

## 手順

### フォーラムを作る(管理者)

1. コミュニティ機能をオンにしておく([11-community.md](11-community.md))
2. チャンネル一覧で、カテゴリーの横の「**+**」を押す(「チャンネルを作成」)
3. チャンネルの種類で「**フォーラム**」を選ぶ
4. チャンネル名を入れる。特定のロールの人だけに見せたいときは、プライベートチャンネルにする
5. 「チャンネルを作成」を押す

- チャンネルを作るには「チャンネルの管理」の権限が要る(非公式の情報)
- 種類の一覧に「フォーラム」が出ないときは、コミュニティ機能がオフになっていないかを見る

### 作ったあとにやること(管理者)

公式ブログでは、作ったあとに次のことをすすめている。

| やること | 内容 |
|---|---|
| 権限を決める | 誰が投稿を立てられるか(@everyone か、特定のロールだけか)。おすすめの権限を入れるボタンがある(英語版は「Set recommended permissions」) |
| 投稿ガイドラインを書く | どんな投稿をしてほしいか、タグの選び方、同じ話題がすでにあるときどうするか、など。投稿を立てる人に見える |
| デフォルトのリアクションを決める | すべての投稿に、最初からリアクションのボタンとして出す絵文字を1つ決める(例:👍) |
| タグを作る | 投稿の分類に使う短い言葉。例:「質問」「解決済み」「要望」 |
| 最初の投稿を立てる | 見本として、管理者が1つ投稿を立てておく |

ほかに、次のような設定もある(非公式の情報)。

- **並び替え**のふつうの値:「最新のアクティビティ」(最近話された順)か「作成日時」(新しく立った順)
- **表示のしかた**:リスト表示か、ギャラリー表示(画像が大きく出る。作品の紹介などに向く)
- **非アクティブになったら隠す**までの時間(英語版は「Hide After Inactivity」):1時間・24時間・3日(ふつうの値)・1週間。話されなくなった投稿は、一覧の下の「古い投稿」の方に移る。だれかが書きこむと、また上に出る
- **スローモード**:投稿を立てる回数と、投稿の中のメッセージの両方を、決まった間隔に1回までにできる

### 投稿を立てる(メンバー)

1. フォーラムチャンネルを開く
2. 投稿ガイドラインを読む(フォーラムの上や横に出る)
3. 「**新しい投稿**」を押す
4. **タイトル**(必ず入れる)と、最初のメッセージを書く。画像も付けられる
5. 合うタグを選ぶ(1つの投稿に5つまで、という情報がある)
6. 「投稿」を押す

- 同じ話題の投稿がもうないか、先に検索するとよい
- 投稿を立てるには、そのフォーラムで「メッセージを送信」できる権限が、投稿の中で返事をするには「スレッドでメッセージを送信」の権限が要る(非公式の情報。フォーラムはスレッドのしくみでできているため)

### 投稿を探す

- フォーラムの上の**検索の欄**で、キーワードで探せる。タイトルだけが対象という情報と、タグ名や投稿した人の名前でも探せるという情報があり、**どちらか未確認**
- **タグ**を押すと、そのタグの付いた投稿だけにしぼれる。いくつかのタグを選んでしぼることもできる

## タグ

- 1つのフォーラムに**20個まで**作れる(複数の非公式の情報で一致)
- タグには絵文字も付けられる
- 「**投稿時にタグを要求**」(英語版は「Require a tag」などと書かれている)をオンにすると、タグを1つも選ばないと投稿を立てられない
- **モデレーターだけが付けられるタグ**も作れる。たとえば「解決済み」「対応中」を、管理する人だけが付けられるようにする(非公式の情報。付けられるのは「スレッドの管理」の権限を持つ人)
- タグに色を付ける機能はない。日本語の解説にある「解決済み=緑」のような例は、名前の付け方の工夫

### 使い方の例:質問チャンネル

| タグ | 付ける人 | 意味 |
|---|---|---|
| 質問 | 投稿した人 | 質問の投稿 |
| 要望 | 投稿した人 | 機能の要望など |
| 対応中 | モデレーター | 返事をしているところ |
| 解決済み | モデレーター | 解決した。あとから同じことで困った人が探せる |

## 投稿を閉じる・ロックする(管理者・モデレーター)

非公式の情報からまとめた。

- 投稿を右クリックして「**投稿を閉じる**」(英語版は「Close Post」)を選ぶと、その投稿は閉じた状態になり、新しい投稿の一覧から外れる
- **ロック**すると、モデレーターでない人は返事を書けなくなる。ロックしていない投稿は、書きこむとまた開く
- 投稿を閉じる・開く・ロックする・名前を変える・消すには、「**スレッドの管理**」の権限が要る
- フォーラムのいちばん上に、投稿を1つだけ**ピン留め**できる(例:よくある質問、ルール)

## 通知

- フォーラムの投稿の通知は、ふつう、**自分がフォローしている投稿だけ**に来る(非公式の情報)。自分が立てた投稿や書きこんだ投稿は、フォローした状態になると思われる(未確認)
- 通知を減らす方法は [02-notifications.md](02-notifications.md)
