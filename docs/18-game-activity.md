# ゲームを起動すると左下に出るもの

## 要点

- PC版のDiscordを起動したままゲームをすると、Discordがそのゲームを**自動で見つけて**、画面左下(自分の名前の上)に枠を出す(2026-11-18 実機で確認)
- 出てくるのは、主に次の3つ
  1. **ゲーム名と「共有しない ⌄」**:遊んでいるゲームを、ほかの人に見せるかどうかの切りかえ
  2. **モニターのアイコン**:ゲームの画面を**配信**(画面共有)するボタン
  3. **「報酬ゲット!」と会社のロゴ**:「**クエスト**」の宣伝。押さなければ何も起きない
- どれも、放っておいて問題ない。ゲームを閉じれば消える(消えることは未確認)

## 画面の見方(PC版)

実機(2026-11-18)では、左下が上から次のように並んでいた。

| 場所 | 表示の例 | 意味 |
|---|---|---|
| いちばん上 | 「ROCKSTAR GAMES」のロゴと「報酬ゲット!」のボタン | クエストの宣伝(下の「クエスト」) |
| まんなか | 「Rogue」、その下に「共有しない ⌄」、右にモニターのアイコン | 見つけたゲームの名前と、公開の切りかえ、配信のボタン |
| いちばん下 | 自分の名前、マイク・ヘッドホン・歯車 | いつもの自分の欄 |

- ここに出るゲーム名は、Discordが見つけたゲーム。いま遊んでいるゲームの宣伝とは限らない(上の例では、遊んでいたのは「Rogue」で、宣伝は Rockstar Games のもの)

## 「共有しない」を押すと

「共有しない ⌄」を押すと、小さな画面が出る(2026-11-18 実機で確認)。

- 「**アクティビティを共有**」のスイッチ。説明は「プレイ中のゲームや連携済みアプリのアクティビティ情報を共有します。」
- スイッチの下に、緑の点と「**ステータスをオンラインに設定**」
- 「**共有**」の行。ゲームやアプリのアイコンが並び(実機では「+14」)、「>」で先に進める

### 読み取れること

- スイッチがオフ(左)なら、ほかの人に「〇〇をプレイ中」と見せない
- 実機では、自分の状態が「**オンライン状態を隠す**」になっていた。オンライン状態を隠していると、プレイ中のゲームもほかの人には出ない(ネットの情報)。そのため「共有しない」になっていると思われる
- 「ステータスをオンラインに設定」とあるので、スイッチをオンにすると、自分の状態も「オンライン」に変わると思われる(**未確認**)。**オンライン状態を隠したい人は、オンにしない方がよい**
- 「共有」の行の先では、ゲームやアプリごとに見せる・見せないを選べると思われる(**未確認**)

## プレイ中のゲームを見せたくないとき

- いちばん簡単なのは、左下の「共有しない」のまま(スイッチをオフのまま)にしておくこと
- 全体の設定は、「ユーザー設定」(左下の歯車)の「**アクティビティのプライバシー**」にある「現在のアクティビティをステータスとして表示」をオフにする(ネットの情報。画面の表記は**未確認**)
- 自分の状態を「オンライン状態を隠す」にしている間は、プレイ中のゲームも出ない(ネットの情報)

## 配信のボタン(モニターのアイコン)

- 押すと、ゲームの画面を**配信**(画面共有)できる。ボイスチャンネルにいる人が、その画面を見られる(押したときの画面は**未確認**)
- 配信を高画質にしたいときは Nitro が必要になる([08-nitro.md](08-nitro.md))

## クエスト(「報酬ゲット!」)

- ゲームなどの会社が出す「お題」(そのゲームを一定時間遊ぶ、配信する、動画を見る など)をこなすと、特典がもらえる機能(Discord公式)
- 「報酬ゲット!」のボタンや、「発見」(画面の左端、サーバー一覧のいちばん下)の「クエスト」から、内容を見て「クエストを受ける」(英語では Accept Quest)を押すと始まる。押さなければ始まらない(Discord公式。日本語の表記は**未確認**)
- ゲームを遊ぶお題は、PC版のアプリが必要(ブラウザ版ではゲームを見つけにくいため)(Discord公式)
- 「発見」については [17-apps.md](17-apps.md) も参照

### 「報酬ゲット!」を押したときの画面

2026-11-18 に実機で押すと、次の画面が出た。

| 場所 | 表示 |
|---|---|
| 左上 | 「報酬」「Discord Orbs」 |
| 左 | Orbs のマークと「200」、「Orbs残高は現在200です。さっそく使ってみましょう。」、「ショップを見てみる」のボタン |
| 右 | 「ROCKSTAR GAMES」のロゴと、「『グランド・セフト・オートVI』:プリロードクエスト」「『GTAVI』11月19日登場。今すぐプレオーダー&プリロードしよう。」 |
| 右下 | リンクのアイコンと、「ダウンロード ↗」のボタン |
| 右上 | 「×」(閉じる) |

- このクエストの特典は「**Discord Orbs**」。Orbs は、クエストでもらえるDiscordの中のポイントで、「ショップ」でアバターの飾りなどと交換できる(ネットの情報。くわしくは**未確認**)
- 「ダウンロード ↗」は、宣伝しているゲームの販売ページなどへ移るボタンと思われる(「↗」は外のページへ移る印。押した先は**未確認**)。ゲームを買う気がなければ押さなくてよい
- 「×」で閉じれば何も起きない
- クエストの中身(お題・特典)は、時期によって変わる。上の画面は 2026-11-18 の例
- 残高が「200」と出ていたが、このクエストでもらったものか、前からあったものかは**未確認**

## メモ

- 実機で確かめたのは、左下の表示、「共有しない」を押したときの画面、「報酬ゲット!」を押したときの画面だけ。スイッチをオンにしたときの動き、「共有」の先、配信のボタン、クエストの受け方・お題のこなし方、Orbs の使い道は**未確認**
- ゲームを見つけるのは PC版のアプリ。スマホ版やブラウザ版で同じ表示が出るかは**未確認**
- 実機の画面の自分の状態は「オンライン状態を隠す」だった。ほかの状態(オンライン、退席中など)のときは、「共有しない」ではなく別の表示になるかもしれない(**未確認**)
