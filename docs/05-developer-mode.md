# 開発者モードとIDのコピー

## 要点

- Botを作るときなどに必要な「チャンネルID」「ユーザーID」「サーバーID」は、開発者モードをオンにするとコピーできる

## 手順(PC)

1. 左下の、マイク・ヘッドホンのアイコンの横にある歯車「ユーザー設定」
2. 左メニューの「開発者」→「開発者モード」をオン
3. コピーしたいものを右クリック → メニューの一番下にあるコピー項目を選ぶ
   - チャンネル:「チャンネルIDをコピー」
   - ユーザー(メッセージ横のアイコンなど):「ユーザーIDをコピー」
   - サーバー(左端のサーバーアイコン):「サーバーIDをコピー」

## メモ

- 以前は「詳細設定」の中にあったが、現在は左メニューの「開発者」に移っている(2026-11-04 デスクトップ版 1.0.9266 で実機確認)
