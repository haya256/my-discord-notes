# 文字(フォント)の大きさを変える

## 要点

- PC版では、「ユーザー設定」→「**ユーザー補助**」→「テキストの読みやすさ」の「**チャットのテキストサイズ**」で、チャットの文字を大きくできる(2026-11-15 実機で確認)
- 以前は「外観」の中の「チャットの文字スケーリング」だった。ネット上の古い記事には「外観」と書かれていることがある
- 画面全体(メニューやボタンも)を大きくしたいときは、同じ「ユーザー補助」の「ビジュアル密度」にある「**拡大率**」を使う(以前の「ズームレベル」)
- PC版では、キーボードの **Ctrl と +**(Macは ⌘ と +)で、すぐに画面全体を拡大できる。**Ctrl と 0** で元に戻る
- 設定は端末ごと。PCで変えても、スマホの表示は変わらない

## どちらを使うか(PC版)

| 設定 | 大きくなるもの | 向いているとき |
|---|---|---|
| 「チャットのテキストサイズ」 | メッセージの文字だけ | 本文だけ読みやすくしたい。チャンネル一覧などはそのままでよい |
| 「拡大率」 | ボタン・メニュー・アイコンを含む画面全体 | メニューの文字も小さくて読みにくい。全体を大きくしたい |

- 両方を組み合わせてもよい。まず「チャットのテキストサイズ」を試し、それでもメニューなどが読みにくければ「拡大率」も上げる

## 手順(PC版・ブラウザ版)

1. 「ユーザー設定」を開く(画面左下の、自分の名前の横にある**歯車のアイコン**)
2. 左メニューの「体験」の中にある「**ユーザー補助**」を開く
3. 「**テキストの読みやすさ**」の「**チャットのテキストサイズ**」のスライダーを右に動かす(右ほど大きい)。上の「プレビュー」で見え方を確かめられる
4. 画面全体を大きくしたいときは、同じ画面を下に進んだ所の「**ビジュアル密度**」にある「**拡大率**」のスライダーを右に動かす
5. Esc キーか右上の「×」で閉じる。設定は自動で保存される(ネットの情報。未確認)

- スライダーの目盛りは **12px・14px・15px・16px・18px・20px・24px**。ふつうは **16px**(目盛りが緑色で示されている)(2026-11-15 実機で確認)
- 「ユーザー補助」には、ほかに「ビジュアル密度」「色・コントラスト」「視差効果を減らす設定」「音声・スクリーンリーダ」などの項目がある(2026-11-15 実機で確認)
- 「拡大率」の説明は「インターフェースのサイズを調整します。ctrl +/- でも変更できます。」。目盛りは **50・67・75・80・90・100・110・125・150・175・200**。ふつうは **100**(2026-11-15 実機で確認)
- 「拡大率」のすぐ上には「**メッセージグループ間のスペース**」(メッセージのまとまりどうしの間隔。0px・4px・8px・16px・24px、ふつうは 16px)もある。行が詰まって読みにくいときは広げるとよい(2026-11-15 実機で確認)
- 「拡大率」と「メッセージグループ間のスペース」は、どちらも「ユーザー補助」の「**ビジュアル密度**」の中にある(2026-11-15 実機で確認)
- 以前は「外観」の中に「ズームレベル」としてあった。ネット上の古い記事には「ズームレベル」と書かれていることがある

### キーボードで拡大・縮小する

| キー(Windows) | キー(Mac) | 動き |
|---|---|---|
| Ctrl と + | ⌘ と + | 画面全体を拡大 |
| Ctrl と - | ⌘ と - | 画面全体を縮小 |
| Ctrl と 0 | ⌘ と 0 | 元の大きさ(100%)に戻す |

- キーボードで変えると、「拡大率」の値が変わる(画面に「ctrl +/- でも変更できます」とある)。Ctrl と 0、Mac の ⌘ で同じように動くかは未確認
- うっかり Ctrl と - を押して、急に字が小さくなることもある。そのときは **Ctrl と 0** で戻る

## 手順(スマホ版)

1. 右下の自分のアイコンを押す
2. 右上の歯車のアイコンを押して設定を開く(アプリの版によっては、アイコンを押すとすぐに設定が出る)
3. 「**外観**」を開く(PC版と同じく「ユーザー補助」に移っているかもしれない。未確認)
4. 文字の大きさの項目(「チャットの文字サイズ」など)で、大きさを選ぶ

- 画面の表記や選べる段階の数は、iPhone と Android、アプリの版で違うことがある(ネットの情報。未確認)
- Discordの中に設定が見つからないときは、スマホ本体の設定で文字を大きくする方法もある(iPhone は「設定」→「画面表示と明るさ」→「テキストサイズを変更」、Android は「設定」→「ディスプレイ」→「フォントサイズ」など。機種によって違う)。ただし、ほかのアプリの文字も大きくなる

## メモ

- 実機で確かめたのは、PC版の「ユーザー補助」の画面(「チャットのテキストサイズ」「拡大率」「メッセージグループ間のスペース」)だけ。キーボードでの拡大の実際の動き・スマホ版は**未確認**
- 以前の「外観」は、今は左メニューの「テーマ」になっているようだ(**未確認**。左メニューに「外観」はなく「テーマ」があった)
- 「チャットのテキストサイズ」で変わるのはメッセージの文字だけ。チャンネル名やサーバー名の文字は変わらない(ネットの情報。未確認)
- 文字の大きさの設定は、ほかの人の見え方には影響しない。自分の画面だけが変わる
