# アプリ(発見のアプリ)

> **注意**:この記事の中で例として出てくる Craig は、Discordの公式機能ではありません。外部の開発者が提供するサードパーティのサービスです(公式サイト:https://craig.chat/)。紹介はしますが、推奨や保証はしません。

## 要点

- 「発見」の「**アプリ**」は、Discordに**付け足して使える機能**(アプリ)のカタログ。昔の「Bot」も、通話の中で遊べるゲームや動画の同時視聴(**アクティビティ**)も、今はまとめて「アプリ」と呼ばれている
- アプリの追加先は2つ。**サーバーに追加**(サーバーの全員が使える。「サーバー管理」の権限が要る)と、**自分のアカウントに追加**(自分だけが、どのサーバーやDMでも使える)
- **アプリのほとんどは、Discord以外の開発者が作ったもの**。追加するときは、どんな権限や情報を求めているかを見てから決める
- 管理者は、ロールの権限で、メンバーがアプリやアクティビティを使えるかどうかを決められる

## 「発見」の「アプリ」の画面

PCでは、サーバー一覧(画面の左端)のいちばん下にある「発見」のアイコンから開く(2026-11-18 実機で確認)。左のメニューに「アプリ」「サーバー」「クエスト」が並ぶ(実機で確認)。

- **アプリ**:アプリのカタログ。上のタブで「注目」「ゲーム」「エンターテインメント」「管理とツール」「交流」「ユーティリティ」に分かれていて、右上の「検索」で名前を探せる(実機で確認)
- **サーバー**:公開されているサーバーを探す
- **クエスト**:ゲームなどの宣伝の「お題」をこなして、特典をもらう機能(この記事ではあつかわない)

### 並んでいたアプリの例(実機)

| 名前 | 分類 | 何ができるか(説明文より) |
|---|---|---|
| Watch Together | ユーティリティ | 友だちとYouTubeのプレイリストを作って、一緒に見る |
| Lofi | (表示なし) | Lofi音楽と雰囲気を、友だちと楽しむ |

- 説明文は英語のものが多かった

- 一覧のアプリのうち、どれがDiscord自身のもので、どれが外部の開発者のものかは、画面からは見分けにくい。各アプリのページで開発者を確かめる

## アプリの種類

| 種類 | どんなものか | 例 |
|---|---|---|
| Bot(ボット) | サーバーのメンバーのようにふるまって、メッセージに返事したり、管理を手伝ったりする。メンバー一覧に「BOT」の印が付く | 荒らし対策、音楽、録音([07-voice-recording.md](07-voice-recording.md) の Craig など) |
| コマンド | チャット欄で `/` を打つと、使えるコマンドが一覧で出る。アプリが追加されていると、そのアプリのコマンドが並ぶ | `/help`、`/about` など |
| アクティビティ | ボイスチャンネルやDMの通話の中で、みんなで遊ぶゲームや、同時に見る動画など | Watch Together、Whiteboard、ゲーム |

- 1つのアプリが、Botとコマンドとアクティビティを兼ねていることもある

### 例:Craig(録音のBot)

ボイスチャンネルの録音に使う Craig も、今の呼び方では「アプリ」の一つ。くわしい使い方は [07-voice-recording.md](07-voice-recording.md) を参照。

- **Craig は Discord の公式機能ではなく、外部の開発者が提供するサービス**。「アプリ」として追加できても、Discord が作ったものではない
- アプリの種類のうち、**Bot** と **コマンド** の2つを兼ねている
  - Bot:ボイスチャンネルに入って、話す人ごとに録音する
  - コマンド:`/join`(録音を始める)、`/stop`(止める)などで操作する
- 追加先は「**サーバーに追加**」の方。追加するには、そのサーバーで「サーバー管理」の権限が要る
- 追加のしかたは2通りある
  - Craig の公式サイト(https://craig.chat/)の「Add to Discord」から([07-voice-recording.md](07-voice-recording.md) の手順)
  - アプリディレクトリで「Craig」を検索して、「アプリを追加」から(非公式の解説より。今の「発見」の「アプリ」の画面で見つかるかは未確認)
- どちらの場合も、似た名前の偽物に気をつける。追加する前に、アプリのページの開発者やリンク先が公式サイト(craig.chat)になっているかを見る
- 「アクティビティを使用」などの権限とは関係なく、Craig を使えるかどうかは「アプリコマンドを使用」の権限で決まると考えられる(下の「管理者ができること」。未確認)

## 追加のしかた:サーバーに追加するか、自分に追加するか

アプリのページの「アプリを追加」(英語版は Add App)を押すと、どこに追加するかを選ぶ(公式ブログより。日本語版の表記は未確認)。

| | サーバーに追加(Add to Server) | 自分のアカウントに追加(Add to My Apps) |
|---|---|---|
| 使える人 | そのサーバーのメンバー全員 | 自分だけ |
| 使える場所 | そのサーバーの中 | 入っているどのサーバーでも、DMでも |
| 追加できる人 | 「サーバー管理」の権限を持つ人 | 誰でも |
| できること | 追加するときに認めた権限の範囲で、サーバーの中で動ける(メッセージを消す、ロールを付ける など) | サーバーやDMの情報は読めない。できるのは、コマンドへの返事などに限られる |
| 外すとき | 「サーバー設定」の「連携サービス」(英語版は Integrations)から(と思われる。未確認) | 「ユーザー設定」の「認証済みアプリ」(英語版は Authorized Apps)から |

- サーバーに追加するときは、アプリが求める権限の一覧が出て、チェックを入れて認める。**「管理者」の権限を求めるアプリは、本当に必要かよく考える**([13-roles.md](13-roles.md) の「よくある失敗」も参照)
- サーバーに追加したアプリにも、専用のロールが付く。ロールの順番が効くので、アプリが思ったとおりに動かないときは、アプリのロールの位置を見る([13-roles.md](13-roles.md) の「ロールの順番」)
- 自分のアカウントに追加する機能は、2024年ごろから少しずつ使えるようになった(公式ヘルプの要約より)

## アクティビティの始め方

1. ボイスチャンネルに入る(またはDMで通話を始める)
2. 通話の画面のロケットのボタン(アクティビティのボタン)を押す
3. 遊びたいアクティビティを選ぶ

- 通話にいるほかの人は、そのアクティビティに参加できる
- Watch Together では、操作する人(コントローラー)が1人決まる(公式ブログより)
- ロケットのボタンの見た目と場所は、Discordの画面の変更で変わっている可能性がある(未確認)

## 管理者ができること(権限)

ロールの権限で、メンバーがアプリを使えるかどうかを決められる([13-roles.md](13-roles.md) を参照)。英語の名前は公式ヘルプ・開発者向けドキュメントより。日本語版の表記は未確認。

| 権限 | オフにすると |
|---|---|
| アプリコマンドを使用(Use Application Commands) | サーバーに追加したアプリも含めて、`/` のコマンドが使えなくなる |
| アクティビティを使用(Use Activities) | ボイスチャンネルでアクティビティを始められなくなる |
| 外部のアプリを使用(Use External Apps) | メンバーが**自分のアカウントに追加したアプリ**が、そのサーバーで**みんなに見えるメッセージを出せなくなる**(返事は使った本人にだけ見える)。サーバーに追加したアプリには影響しない |

- どれも、サーバー全体(ロール)でも、チャンネルごとの上書きでも設定できる
- 「Watch Together が見つからない」というメンバーがいたら、「アクティビティを使用」がそのロールやチャンネルでオフになっていないかを見る
- 設定したら、「ロールとして表示」でメンバーからの見え方を確かめるとよい([13-roles.md](13-roles.md) の「設定を確かめる」)

- アプリの中には、有料のプラン(プレミアム)があるものもある
- Craig のことは、[07-voice-recording.md](07-voice-recording.md) の情報(Craig の公式サイトのまとめ。実機では未確認)をもとに書いた
