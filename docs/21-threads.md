# スレッド

## 要点

- スレッドは、チャンネルの中の**1つのメッセージから枝分かれして話す、小さな会話の場所**。横道の話や、長くなりそうなやりとりを、チャンネルの流れから外して続けられる
- 種類は2つ:**パブリックスレッド**(そのチャンネルを見られる人はだれでも見られる)と、**プライベートスレッド**(招かれた人とモデレーターだけ)
- しばらく話されないと、**自動でアーカイブ**(しまわれる)される。消えるわけではなく、書きこむとまた開く
- 作る・中で話す・管理するには、それぞれ専用の権限がある(「パブリックスレッドを作成」「プライベートスレッドを作成」「スレッドでメッセージを送信」「スレッドの管理」)
- 話題ごとに投稿を立てる「フォーラムチャンネル」も、中身はスレッドでできている([20-forum.md](20-forum.md))

この記事は、ネットの情報からまとめたもの。実機では確認していない。日本語の画面の名前は、非公式の日本語の解説からとったもので、今の画面と違うことがある。

## スレッドとは

ふつうのテキストチャンネルでは、みんなの話が1つの流れに続けて書かれる。そこで2人が細かい話を始めると、ほかの話がまぎれて読みにくくなる。

スレッドを作ると、その話だけを**チャンネルの横に分けて**続けられる。

| | チャンネルで返信 | スレッド |
|---|---|---|
| 書かれる場所 | チャンネルの流れの中 | チャンネルから分かれた別の場所(右に開く) |
| ほかの話とのまざり方 | まざる | まざらない |
| 見られる人 | チャンネルを見られる人 | パブリック:チャンネルを見られる人/プライベート:招かれた人だけ |
| 話されなくなったら | そのまま流れていく | 自動でアーカイブされる |

- スレッドは、元のチャンネルの権限を**そのまま受けつぐ**。スレッドごとに権限は決められない(公式の開発者向けドキュメント)
- スレッドは、サーバーのチャンネル数の上限には数えられない(公式の開発者向けドキュメント)
- 話されている間のスレッドは、左のチャンネル一覧で、元のチャンネルの下に出る。アーカイブされると、一覧から消える(非公式の情報)

## 手順

### メッセージからスレッドを作る

1. スレッドにしたいメッセージにマウスを重ねる
2. 出てきたボタンの中の「**スレッドを作成**」(吹き出しのような形)を押す。見つからないときは「…」(その他)の中を見る
3. スレッドの名前を入れる
4. 最初のメッセージを書いて送る

- 元のメッセージの下に、スレッドへの案内が出る。押すと、だれでもスレッドに入れる(パブリックスレッドの場合)
- 元のメッセージが消されても、スレッドは残る(公式の開発者向けドキュメント)

### チャンネルの上からスレッドを作る

1. チャンネルを開き、上の「**スレッド**」のボタン(#に吹き出しが付いたような形)を押す
2. 「**スレッドを作成**」を選ぶ
3. 名前と最初のメッセージを入れる。プライベートスレッドにしたいときは、ここで「プライベートスレッド」をオンにする
4. 作成する

- チャット欄の左の「**+**」から「スレッドを作成」を選ぶ方法もある(非公式の情報)
- ボタンの形と名前は非公式の解説からで、今の画面とは違うことがある

### プライベートスレッドに人を入れる

- プライベートスレッドの中で、入れたい人を **@メンション**すると、その人がスレッドに加わる(公式ブログ・非公式の解説)
- 作った人は、だれでも人を招けるようにするかどうかを決められる、という情報がある(非公式の情報。未確認)
- 「スレッドの管理」の権限を持つ人(モデレーター)は、招かれていなくてもプライベートスレッドを見られる

## パブリックスレッドとプライベートスレッド

| | パブリックスレッド | プライベートスレッド |
|---|---|---|
| 見られる人 | 元のチャンネルを見られる人はだれでも | 招かれた人と、「スレッドの管理」の権限を持つ人だけ |
| 作り方 | メッセージから、またはチャンネルの上から | チャンネルの上から(メッセージからは作れない) |
| 作れるチャンネル | テキストチャンネル、アナウンスチャンネル | テキストチャンネルだけ |
| 要る権限 | 「パブリックスレッドを作成」 | 「プライベートスレッドを作成」 |

- 作れるチャンネルとメッセージからは作れないことは、公式の開発者向けドキュメントによる
- プライベートスレッドは、はじめ(2021年)は**サーバーブーストのレベル2**がないと使えなかった。今は**ブーストなしで使える**(非公式の情報で、Discordの管理者向けのお知らせを引いている)。古い解説にはまだ「レベル2が必要」と書いてあるものがあるので注意
- プライベートスレッドは、モデレーターからは見える。**だれにも見られない場所ではない**

## アーカイブ(しまわれる)

しばらくだれも書きこまないと、スレッドは自動で**アーカイブ**される。

- アーカイブされたスレッドは、左のチャンネル一覧から消えるが、**消えたわけではない**。中身はそのまま読める
- だれかが書きこむと、また開く(ロックされていなければ)
- 自動でアーカイブされるまでの時間は、**1時間・24時間・3日・1週間**から選べる、という情報がある(非公式の情報。2026年の解説ではブーストなしで選べるとしている)
  - 古い解説には「3日・1週間はブーストが必要」「ブーストでさらに長くできる」と書いてあるものがある。今の決まりは**未確認**
- チャンネルごとに、新しいスレッドのふつうの値を決められる(公式の開発者向けドキュメント)
- 作った人と、「スレッドの管理」の権限を持つ人は、手でアーカイブしたり、時間を変えたりできる

### アーカイブされたスレッドを探す

1. 元のチャンネルを開き、上の「スレッド」のボタンを押す
2. スレッドの一覧が出る。アーカイブされたものは「**アーカイブ済み**」などの欄にある(非公式の情報)

- チャンネルの検索でも、アーカイブされたスレッドの中のメッセージが見つかる(非公式の情報)

## ロック(管理者・モデレーター)

- スレッドを**ロック**すると、「スレッドの管理」の権限がない人は書きこめなくなる。アーカイブもモデレーターしか解けなくなる(公式の開発者向けドキュメント)
- 話を終わらせたいときは、アーカイブとロックをいっしょにすると、モデレーターでないと開けなくなる(非公式の情報)

## 通知

- スレッドに入ると(自分で作った、書きこんだ、メンションされたなど)、そのスレッドの通知が来るようになる、と考えられる(未確認)
- スレッドごとに、通知を「すべてのメッセージ」「@メンションのみ」「なし」から選べる、という情報がある(非公式の日本語の解説。未確認)
- スレッドから**抜ける**(退出する)と、通知も来なくなる(未確認。手順も未確認)
- 通知を減らす方法は [02-notifications.md](02-notifications.md)

## 権限

スレッドには、専用の権限がある。チャンネルやロールの権限の設定で決める(権限のしくみは [13-roles.md](13-roles.md))。

| 権限(日本語の名前は非公式) | できること |
|---|---|
| 「**パブリックスレッドを作成**」 | パブリックスレッドを作る |
| 「**プライベートスレッドを作成**」 | プライベートスレッドを作る |
| 「**スレッドでメッセージを送信**」 | スレッドの中で書きこむ |
| 「**スレッドの管理**」 | スレッドを消す、ロックする、スローモードを決める、すべてのプライベートスレッドを見る、名前を変える、アーカイブする・戻す |

- スレッドの中で書きこむには「**スレッドでメッセージを送信**」が要る。ふつうの「メッセージを送信」は、スレッドの中では効かない(公式の開発者向けドキュメント)
  - そのため、「チャンネルには書けないが、スレッドでは話せる」という設定ができる。たとえば、アナウンスチャンネルで「メッセージを送信」を切って「スレッドでメッセージを送信」だけ許すと、お知らせ1件ごとにスレッドで話してもらえる(非公式の解説の使い方の例)
- スレッドを見るには、元のチャンネルを見る権限(「チャンネルを見る」)が要る

### 作った人と管理する人ができること

公式の開発者向けドキュメントから。

| 操作 | 作った人 | 「スレッドの管理」の権限を持つ人 |
|---|---|---|
| 名前を変える | できる | できる |
| アーカイブする・戻す | できる | できる |
| 自動アーカイブの時間を変える | できる | できる |
| ロックする | できない | できる |
| スローモードを決める | できない | できる |
| 消す | できない | できる |

- 作った人は、自分のプライベートスレッドから人を外せる、という情報がある(非公式の情報)

## Slack のスレッドとのちがい

Slack を使ったことがある人は、Slack のスレッドと同じものだと思いやすい。どちらも「メッセージから枝分かれして、右に開いて話す」点は同じだが、次の点がちがう。

| | Slack のスレッド | Discord のスレッド |
|---|---|---|
| 作り方 | メッセージの「スレッドで返信する」を押して、返信を書くだけ | 「スレッドを作成」を押して、**名前を付けて**作る |
| 名前 | なし(元のメッセージがそのまま見出しになる) | あり。元のメッセージとは別に名前を付ける |
| 作れる人 | チャンネルで書きこめる人はだれでも | 「パブリックスレッドを作成」などの権限がある人 |
| 非公開にできるか | できない。チャンネルにいる人はだれでも見られる | プライベートスレッドにすると、招かれた人とモデレーターだけになる |
| 話されなくなったら | そのまま残る | 自動でアーカイブされ、左の一覧から消える(書きこむとまた開く) |
| 左の一覧 | 出ない | 話されている間は、元のチャンネルの下に出る |
| チャンネルにも流す | 「チャンネルにも投稿する」にチェックを入れたときだけ、返信をチャンネルにも出せる | スレッドの中の書きこみは、**チャンネルには流れない**。チャンネルにも出す機能はない(未確認) |
| 権限 | チャンネルの権限と同じ | スレッドで書きこむには「スレッドでメッセージを送信」が別に要る |
| ふだんの使い方 | 返信はスレッドで、が当たり前になっていることが多い | チャンネルでそのまま返信(「返信」のボタン)することが多く、スレッドは長くなる話のときに作る |

つまり、Slack のスレッドは**メッセージへの返信をまとめる場所**、Discord のスレッドは**メッセージから作る小さなチャンネル**に近い。Discord で「ちょっと返事をしたい」だけなら、スレッドを作らずにメッセージの「返信」を使う方がふつう(返信のしくみは [22-reply.md](22-reply.md))。

- Slack の情報は、Slack の公式ヘルプ(日本語)と、一般的に知られていることからまとめた。Slack の画面での名前や、今の決まりは未確認
- Discord では、スレッドの中の書きこみはチャンネルには出ない。チャンネルに出るのは、スレッドができたことの知らせ(メッセージから作ったときは元のメッセージの下に、チャンネルの上から作ったときは「〜がスレッドを始めました」のような知らせ)と、スレッドの名前・書きこみの数ていど(一般に知られていることから。未確認)
- Discord に「チャンネルにも投稿する」に当たる機能がないことは、資料では確かめていない(未確認)。チャンネルのみんなに伝えたいことは、チャンネルに書き直す

## フォーラムチャンネルとのちがい

| | スレッド | フォーラムの投稿 |
|---|---|---|
| どこにできる | テキストチャンネル・アナウンスチャンネルの中 | フォーラムチャンネルの中 |
| 主役 | チャンネルの流れ(スレッドは横道) | 投稿(チャンネルの流れはない) |
| 分け方 | なし | タグ |
| 条件 | どのサーバーでも使える | コミュニティ機能が必要 |

- フォーラムの投稿も、しくみはスレッドと同じ。権限もスレッドの権限が使われる。くわしくは [20-forum.md](20-forum.md)
