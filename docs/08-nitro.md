# Nitro(有料プラン)でできること

## 要点

- Nitroは、Discordの月額の有料プラン。**安い「Nitro Basic」と、全部入りの「Nitro」**の2種類がある
- 無料でも、チャット・通話・画面共有など基本の機能はすべて使える。Nitroの特典の多くは、**見た目や表現を豊かにするもの**
- 実用面で効いてくるのは、主に**大きいファイルを送りたい**、**画面共有をきれいに配信したい**、**ほかのサーバーの絵文字を使いたい**とき

## 料金(公式サイトの表示。米ドル)

| プラン | 月額 |
|---|---|
| Nitro Basic | $2.99 |
| Nitro | $9.99 |

日本円での価格は、アプリの「ユーザー設定」→ 左メニューの「Nitro」で確認する(価格は未確認)。

## 主な特典

### Nitro Basic でもできること

- **「どこででも使えるカスタム絵文字」**:あるサーバーの絵文字を、ほかのサーバーやDMでも使える
- **アップロード上限 50MB**(無料は 20MB。`03-files.md` を参照)
- 「カスタムアプリアイコン」:アプリのアイコンを変えられる

### Nitro だけでできること(「Basicの全特典 + さらに追加で」)

- **「1GBのアップロード上限」**
- **「HDビデオストリーミング配信」**:画面共有・配信を高画質にできる
- 「カスタムプロフィール」:プロフィールを凝ったものにできる
- 「アプリのカラーテーマ」
- 「Xbox Game Pass」が付く。ただし**一部地域でのみ利用可能**(日本で使えるかは未確認)

## 入るか迷ったときの目安

| こんなとき | 必要なプラン |
|---|---|
| 今の使い方で困っていない | 無料のままでよい |
| 20MBを超える動画などをよく送る | 50MBまでなら Basic、それ以上なら Nitro。Googleドライブなどのリンクで送れば無料でも済む |
| 画面共有でゲームなどを高画質で見せたい | Nitro |
| 好きなサーバーの絵文字をあちこちで使いたい | Basic |
| 好きなサーバーを応援(ブースト)したい | Nitro |
| 長い文章を1つのメッセージで送りたい(4000文字まで) | Nitro |
| たくさんのサーバーに参加したい(200まで) | Nitro |
