# ファイル送信の容量上限

## 要点

- 無料ユーザーの上限は **1ファイル20MB**(2026年8月に10MBから引き上げ)
- Nitro Basic は 50MB、Nitro は 1GB
- 大きいファイルは、Googleドライブなどにアップしてリンクを貼る

## メモ

- 上限を超えると「おっと、このファイルはサイズ制限を超えています。」と表示され、Nitroの案内が出る(2026-11-04 実機で確認。19MBは送信でき、21MBは送れなかった)
- Nitro Basic の 50MB は実機では未確認。Discord公式のNitroのページ(https://discord.com/nitro)の記載で確認(2026-11-04)
- 2026年8月に10MBから20MBに引き上げられた。ネット上の古い記事には「10MB」「25MB」などと書かれていることがある
- 上限はよく変わるので、`checked` の日付が古ければ公式サポートページで確認する
- 容量内なのに送れないときは、そのチャンネルで「ファイルを添付」の権限があるか確認する
