# 相手の声がロボットボイスのように途切れる

## 事例

> ボイスチャンネルで、自分の環境ではなぜかHさんの声がロボットボイスのように途切れ途切れになり、スムーズに会話できなかった。他の人には問題なく聞こえていた。

- 話していたのは、自分とHさんの2人だけ。ほかの数人は聞くだけで参加していた
- 約1時間、2人で話し続けていた
- 自分はヘッドホンで聞いていた(Bluetoothか有線かは不明)

## 要点

- **他の人には普通に聞こえていたなら、原因はHさん側ではなく自分側**(自分の回線・PC・機器)の可能性が高い
- ロボットボイス(声がカクカク・ブツブツになる)は、多くの場合**音声のデータが途中で欠けている**(パケットロス)ときに起きる
- まず試すのは「通話の入り直し」と「Discordの再起動」。続けて、**Wi-Fi・Bluetooth・PCの負荷**を順に疑う

## 切り分け

Discordの通話は、全員の声がいったんDiscordのサーバーを経由して届く。そのため、誰の声が誰に途切れて聞こえるかで、原因の場所を絞れる。

| 状況 | 疑う場所 |
|---|---|
| Hさんの声が、**全員**に途切れて聞こえる | Hさん側(Hさんの回線・マイク・PC) |
| Hさんの声が、**自分にだけ**途切れて聞こえる | 自分側(自分の回線・ヘッドホン・PC) |
| **全員**の声が、自分にだけ途切れて聞こえる | 自分側。特に回線を疑う |
| 全員が全員の声を途切れて聞く | Discordのサーバー側の不調、または通話の地域(リージョン)の問題 |

今回の事例は2つ目にあたる。聞くだけで参加していた数人には、Hさんの声は普通に聞こえていた。つまりHさんのマイクや回線、Discordのサーバーまでは正常で、**サーバーから自分に届くまでの間か、自分の機器で音声が欠けていた**と考えられる。

### この事例でわかったこと

| 確認したこと | 結果 | わかること |
|---|---|---|
| Hさんには、自分の声がきれいに聞こえていたか | 1時間ずっときれいだった | 自分のマイクと、自分から送る側の回線は正常 |
| 1時間ずっとか、途中からか | 1時間ずっと | 一時的な混雑ではなく、ずっと続く原因(機器や設定)がありそう |
| 聞き専の人の声も途切れたか | 聞き専の人は発言しなかった | 確認できず |
| 何で聞いていたか | ヘッドホン(Bluetoothか有線かは不明) | 出力機器が原因の候補に残る |

送る側は正常で、受け取る側だけがずっと悪かった。そのため、**自分のPCで声を受け取って鳴らす部分**(ヘッドホン・スピーカー、その接続や設定)が最も疑わしい。

### この事例で特に疑わしいもの(疑わしい順)

1. **ヘッドホン・イヤホンなどの出力機器**
   - Bluetoothの場合:Wi-Fiと同じ電波の帯域を使うので、音が途切れることがある。マイクも同じBluetooth機器で使っていると、音質の低い通話用のモードに切り替わる
   - USBのヘッドセットやオーディオ機器の場合も、ドライバーや接続の不調で音が途切れることがある
2. **Discordやパソコンの音声出力の設定**
   - 出力デバイスが意図しない機器になっている、など
3. **受け取る側の回線**
   - 送る側が正常なので可能性は下がるが、ゼロではない

### 次に確かめると絞り込めること

- そのヘッドホンが**Bluetooth(無線)か、有線か**。有線の場合も、USBでつなぐものか、イヤホン端子に挿すものか
  - Bluetoothなら、最有力の原因と考えてよい
  - 有線(イヤホン端子)なら、出力機器そのものより、PCの音声出力の設定や受け取る側の回線を疑う
- 次の通話で、**別の出力機器に変えて**同じように途切れるか。変えて直れば、出力機器が原因と確定できる

## 手順(自分側を疑うとき)

簡単なものから順に試す。

1. **通話を抜けて入り直す**。だめなら**Discordを完全に終了して起動し直す**(ウィンドウを閉じるだけでは終了しないことがある)
2. **回線を確認する**
   - Wi-Fiなら、ルーターに近づく。可能なら有線LANにする
   - 動画の視聴、ゲームやOSのアップデート、クラウドへの同期など、裏で回線を使っているものを止める
   - VPNを使っているなら、一度オフにする
3. **Bluetoothのヘッドホン・イヤホンを疑う**
   - Bluetoothの機器は、**マイクも同時に使うと音質が大きく落ちたり、途切れたりする**ことがある
   - 試しに、有線のイヤホンや、PCのスピーカーで聞いてみる
4. **PCの負荷を確認する**
   - タスクマネージャーで、CPUやメモリを使い切っていないか見る。重いアプリを閉じる
   - ブラウザ版のDiscordを使っているなら、アプリ版を試す
5. **Discordの音声設定を確認する**
   - 「ユーザー設定」→「音声・ビデオ」で、出力デバイスが意図した機器になっているか見る
6. **それでも直らない場合は、サーバーの管理者に頼む**
   - ボイスチャンネルの地域(リージョン)を変えると改善することがある。チャンネルの設定で変えられる(変えると、通話中の全員が一瞬切断される)

## 次の通話の前にできる予防

- 大事な通話は、なるべく有線LAN、有線イヤホンで参加する
- 通話の前に、アップデートやクラウド同期が走っていないか確認しておく
