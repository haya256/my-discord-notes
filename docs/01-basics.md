# 用語の基本

## 要点

- **サーバー**:コミュニティ単位の場所。左端のアイコン列に並ぶ
- **チャンネル**:サーバーの中の部屋。文字で話す「テキストチャンネル」と、通話する「ボイスチャンネル」がある
- **カテゴリー**:チャンネルをまとめるフォルダのようなもの
- **ロール**:メンバーにつける役職。権限(何ができるか)はロール単位で設定する
- **DM**:サーバーの外で、個人同士でやり取りするメッセージ。左上の「ダイレクトメッセージ」アイコンから開く

## 表示名とユーザー名

Discordのアカウントには、名前が2種類ある。

| 種類 | 特徴 |
|---|---|
| **表示名** | 自由に付けられる名前。ほかの人と同じでもよい。チャットではふつうこちらが表示される |
| **ユーザー名** | アカウントごとに1つだけの名前。**ほかの人と重ならない** |

### 自分のユーザー名を確認する(PC)

- 画面左下(マイク・ヘッドホンのアイコンの左)に、自分の**表示名**と、その下に小さく**ユーザー名**が出ている
- 左下の自分のアイコンを押すと、プロフィールが開く。大きい文字が表示名、その下の小さい文字がユーザー名

- 人を確実に見分けたいとき(会員の確認、フレンド申請など)は、表示名ではなく**ユーザー名**を教えてもらう
- ユーザー名が重ならないのは**その時点で**の話。本人がユーザー名を変えると、古い名前はあとでほかの人が使える可能性がある。会員名簿など**長く記録しておくなら、変わらないユーザーID**を控える(入会時にユーザー名で本人を探し、見つけたらIDをコピーして記録する、という流れが楽)
- さらに確実にしたいときはユーザーIDを使う([05-developer-mode.md](05-developer-mode.md) を参照)。IDは、聞く側が開発者モードをオンにしていれば、相手のアイコンを右クリックしてコピーできる。相手に開発者モードを頼む必要はない

## メモ

- 権限は「サーバー全体のロール設定」と「チャンネルごとの上書き設定」の2段階になっている。思った通りに動かないときは、チャンネル側の上書きを確認する
- ユーザー名の表示場所は実機で確認(2026-11-04)。「ユーザー名はほかの人と重ならない」は一般的な知識で、実機では未確認
