# チャンネルの種類とアイコン

## 要点

- チャンネル一覧で名前の左に出るアイコンは、**チャンネルの種類**を表している。種類によって、できることがちがう
- 似たものが多いのは、Discord が「仲間内で話す場所」から「大勢が集まるコミュニティ」へと広がるにつれて、**困りごとごとに専用のチャンネルを足してきた**から(下の「なぜ似たものが多いのか」)
- ふつうのメンバーが気にすればいいのは、ほぼ「**ここで話してよいか**」だけ。迷ったら、`#` のテキストチャンネルで話す
- メガホン・チェックの付いた紙・道しるべなど、見慣れないアイコンの多くは、**コミュニティ機能をオンにしたサーバー**で出てくるもの([11-community.md](11-community.md))

この記事は、ネットの情報からまとめたもの。実機では確認していない。**アイコンの形は、文で説明したもので、見た目は今の画面と違うことがある**。日本語の画面の名前も未確認のものがある。

## アイコンの一覧

### チャンネルの種類

| アイコン(形) | 種類 | なにをする所 | 書きこめる人 | 条件 |
|---|---|---|---|---|
| `#` | テキストチャンネル | 文字で話す。ふつうのチャンネル | ふつうはみんな | なし |
| スピーカー | ボイスチャンネル | 声で話す。画面の共有もできる | ふつうはみんな | なし |
| メガホン(メガフォン) | アナウンスチャンネル | お知らせを出す。ほかのサーバーに届けられる | ふつうは管理する人だけ | コミュニティ機能 |
| チェックの付いた紙(チェックボックスに見える) | ルールチャンネル | サーバーのルールを見せる | ふつうは管理する人だけ | コミュニティ機能 |
| 人のまわりに電波のような線 | ステージチャンネル | 話す人と聞く人に分かれた、講演やラジオのような通話 | 話す人だけ(聞く人は手を挙げて頼む) | コミュニティ機能(と思われる。未確認) |
| 吹き出し | フォーラムチャンネル | 話題ごとに投稿を立てる掲示板 | みんな(投稿を立てる) | コミュニティ機能 |
| 画像のような形(未確認) | メディアチャンネル | 画像や動画を、ギャラリーのように並べて投稿する | みんな | **ほとんどのサーバーでは作れない**(下を参照) |

- **鍵の付いたアイコン**(`#` やスピーカーに鍵が付いたもの)は、種類ではなく「**プライベート**」の印。特定のロールの人にしか見えないチャンネル。権限のしくみは [13-roles.md](13-roles.md)
- フォーラムは [20-forum.md](20-forum.md)、チャンネルの下に出る枝分かれの会話(スレッド)は [21-threads.md](21-threads.md)
- **メディアチャンネル**は、なくなったわけではないが、**試験中(ベータ)で、「サーバーサブスクリプション」(有料の会員のしくみ)を使っている一部のサーバーでしか作れない**(Discord のクリエイター向けサポート。いつの情報かは未確認)。ふつうのサーバーでは、チャンネルを作るときの種類に出てこないし、見かけることもまずない。画像を並べたいときは、フォーラムチャンネルの「ギャラリー」表示が近い([20-forum.md](20-forum.md))

### チャンネル一覧の上に出る項目

チャンネルではないが、チャンネル一覧のいちばん上あたりに出るもの。サーバーによって、出るものと出ないものがある。

| アイコン(形) | 名前 | なにをする所 |
|---|---|---|
| 家 | 「**サーバーHub**」(英語版は Server Hub) | サーバーの様子をまとめて見せるページ、という情報がある(下の「サーバーHubについて」) |
| 道しるべ(案内板) | 「**サーバーガイド**」(英語版は Server Guide) | 新しく来た人向けの**案内のページ**。サーバーの紹介、まずやること、よく使うチャンネルへのリンクなど。チャットはできない |
| 一覧に虫めがねが付いた形 | 「**チャンネル&ロール**」(英語版は Channels & Roles) | 参加したときの質問の答えを直したり、ほかのチャンネルを探して一覧に足したりする(「チャンネルを見る」) |
| カレンダー | 「イベント」 | サーバーの予定の一覧([15-events.md](15-events.md)) |

- 「サーバーHub」と「サーバーガイド」は**別のもの**。家のアイコンと道しるべのアイコンが、別々のサーバーで出ているのを実機で確認した(PC。2026-11-24)。名前とアイコンの形は実機で確認したが、中身は開いていない
- 「サーバーガイド」「チャンネル&ロール」は、新しく来た人を案内するための**オンボーディング**という機能の一部

- サーバーガイドは、管理者が「サーバー設定」→「オンボーディング」の中で作る(公式サポートの検索結果)
- 「チャンネル&ロール」で、参加したときの答えを直したり、チャンネルを探したりできることは、公式サポートの検索結果による

#### サーバーHubについて

ここはネットの情報だけで、実機では中身を確認していない。非公式の解説記事1つと、公式サポートの古い記事による。

- サーバーの出来事や様子を**まとめて見せるページ**。チャンネル一覧のいちばん上にタブとして出る、という情報がある
- **2026年11月の初めごろから出はじめた**という情報がある。管理者が何もしていないのに出てきたり、使われていない古いサーバーに出てきたりすることもあるらしい
- 「server-hub」という名前のチャンネルが、Discord によって自動で作られることがある、という情報もある(未確認)
- 管理者は「サーバー設定」の「エンゲージメント」で、サーバーHubのタブを出す設定(英語版では Show Server Hub tab)をオフにすると消せる、という情報がある(未確認)
- 以前、公式サポートに「Server Home(ベータ)」という、サーバーの出来事をまとめて見せるページの説明があった。似た機能だが、今のサーバーHubと同じものかは未確認
- メンバーとしては、開いて眺めるだけのページで、**使わなくても困らない**。話すのは今までどおり `#` のチャンネル

## なぜ似たものが多いのか

もとの Discord は、ゲーム仲間が集まって話す場所だった。そのころは `#`(文字)とスピーカー(声)の2つで足りた。

その後、何千人・何万人が集まるサーバーが増えて、ふつうのチャンネルでは困ることが出てきた。そのたびに、**困りごとを1つ解くための専用のチャンネル**が足された。

| 困りごと | ふつうのチャンネルだと | 足されたもの |
|---|---|---|
| 大事なお知らせが雑談に埋もれる | だれでも書けるので流れてしまう | **アナウンス**(書く人を絞る。ほかのサーバーにも届けられる) |
| 新しく来た人がルールを読まない | どこにルールがあるかわからない | **ルール**(ルールの場所をはっきりさせる) |
| 新しく来た人がどこから見ればいいかわからない | チャンネルが多すぎて迷う | **サーバーガイド**・**チャンネル&ロール**(案内と、自分に要るチャンネルだけを選ぶ) |
| 質問や話題が流れて、あとから探せない | 話が1本の流れに混ざる | **フォーラム**(話題ごとに投稿を立てる)、**スレッド** |
| 大勢の通話で、みんなが話すと聞きとれない | ボイスはだれでも話せる | **ステージ**(話す人と聞く人を分ける) |
| 作品の画像が会話に流れて見にくい | 画像と話がまざる | **メディア**(画像をギャラリーのように並べる。まだ一部のサーバーだけ) |

つまり、似て見えるものは、**「だれが書くか」「どう並ぶか」がちがう**。

- アナウンス・ルール:書くのは**管理する人**。読む人は読むだけ
- テキスト:**みんな**が1本の流れに書く
- フォーラム・メディア:**みんな**が書くが、話題ごと・作品ごとに分かれて並ぶ
- サーバーガイド:チャンネルではなく、**案内のページ**

そのため、仲間内の小さなサーバーなら、テキストとボイスだけで十分なことが多い。ほかのものは、人が増えて困りごとが出てきたときに使えばよい(コミュニティ機能をオンにしないと使えないものも多い)。

## メンバーとしての見かた(迷ったら)

| アイコン | まずやること |
|---|---|
| 家(サーバーHub) | 気になれば眺める。使わなくても困らない |
| 道しるべ(サーバーガイド) | 来たばかりなら、まず開いて読む |
| チェックの付いた紙(ルール) | 一度読む。ここには書きこまない |
| メガホン(アナウンス) | 読むだけ。通知が多いときはミュートする([02-notifications.md](02-notifications.md)) |
| `#`(テキスト) | 話してよい所。チャンネル名や説明(トピック)で話題を見る |
| 吹き出し(フォーラム) | 話すときは、新しい投稿を立てるか、合う投稿の中で話す |
| スピーカー(ボイス) | 押すと通話に入る。**押しただけで入ってしまう**ので注意([24-voice-join-leave.md](24-voice-join-leave.md)) |
| ステージ | 入ると、ふつうは聞くだけ。話したいときは手を挙げる |

## アナウンスチャンネルについて少しくわしく

- お知らせ用のチャンネル。ほかのサーバーが「**フォロー**」すると、ここに投稿したものが**そのサーバーのチャンネルにも届く**([11-community.md](11-community.md))
- 投稿したあとに「**公開**」(英語版は Publish)を押すと、フォローしているサーバーに届く、という情報がある(未確認)
- メンバーには書きこませず、お知らせ1件ごとにスレッドを作って、そこで話してもらう使い方もある([21-threads.md](21-threads.md) の「権限」)

### 「フォローすると、このチャンネルの最新情報を自分のサーバーで受け取れます。」と出たら

ほかのサーバーのアナウンスチャンネルを開くと、メッセージを書く欄のあたりに、次のような案内が出る(PCで実機で確認)。

> フォローすると、このチャンネルの最新情報を自分のサーバーで受け取れます。　［フォローする］

- これは「**このお知らせを、あなたが管理しているサーバーのチャンネルにも流しませんか**」という案内。自分個人への通知が増えるしくみではない
- 自分のサーバーを持っていない人や、お知らせをよそに流す理由がない人は、**押さなくてよい**(無視してかまわない)
- 通知がうるさいだけなら、フォローではなく**ミュート**で対処する([02-notifications.md](02-notifications.md))
- アナウンスチャンネルでは、ふつうメンバーは書きこめないので、書く欄の代わりにこの案内が出ていると考えられる(未確認)

#### 「フォローする」を押したあとの画面

「**サーバーにこのチャンネルの更新を追加しましょう!**」という画面が出る(PCで実機で確認)。

| 欄 | 選ぶもの |
|---|---|
| 「送信」 | お知らせを届ける先の**サーバー** |
| 「チャンネルを選択」 | そのサーバーの、どの**チャンネル**に届けるか(サーバーを選ぶまでは選べない) |

- 画面の下に「**ウェブフック権限を持っているサーバーとチャンネルのみが表示されます。**」と書いてある。自分に Webhook を管理する権限がないサーバーは、選ぶ欄に出てこない。**ふつうのメンバーとして入っているだけのサーバーには届けられない**ということ([04-webhooks.md](04-webhooks.md)、[13-roles.md](13-roles.md))
- 選んで右下の「フォローする」を押すと、フォローできる。やめるときは「キャンセル」
- 画面の上の説明に、あとから「**サーバー設定**」>「**連携サービス**」>「**チャンネル**」でいつでも削除できる、と書いてある。フォローをやめたいときは、届け先のサーバーの設定から消す
- 届いたお知らせは、元のサーバー名とチャンネル名が付いた、Webhook のような形で表示されるという情報がある(未確認)

## ルールチャンネルについて少しくわしく

- 新しいメンバーにサーバーのルールを見せるチャンネル。コミュニティ機能をオンにするときに、必ず決める([11-community.md](11-community.md))
- 中身はふつうのテキストチャンネルで、アイコンが変わるのは「ルールが書いてある所」という印
- ここに「〇〇が来た!」のような参加メッセージがたくさん流れているときは、**システムメッセージの投稿先**がルールチャンネルになっている。ルールが埋もれるので、管理者は投稿先を別のチャンネルにするとよい([14-system-messages.md](14-system-messages.md))

- 実機で確認したのは、アナウンスチャンネルのフォローの案内の文と「フォローする」のボタン、押したあとの届け先を選ぶ画面まで(PC。2026-11-22)。実際にフォローして、お知らせが届いたときの見た目は未確認
- チャンネル一覧の上に出る「サーバーHub」(家)・「サーバーガイド」(道しるべ)・「チャンネル&ロール」(一覧に虫めがね)は、名前とアイコンだけ実機で確認した(PC。2026-11-24)。中身は開いていない
- サーバーHubの説明は、非公式の解説記事1つと公式サポートの古い記事による。Discord の公式の発表は見つかっていない
- それ以外は実機では確認していない。アイコンの形は非公式の解説などからの文での説明で、Discord の画面が変わると形も変わることがある
- 公式サポートの「Community Onboarding」「Server Guide」は自動では読めず、検索結果に出た一部だけを使った。以前はサーバーガイドが試験中だったという情報もあり、今の状態は未確認
- ステージに、コミュニティ機能が必要かどうかは未確認
- メディアチャンネルが一部のサーバーだけ(試験中)というのは、クリエイター向けサポートの記事の検索結果と、開発者向けドキュメントの「まだ開発中」という書き方による。もっと広く使えるようになっているかは未確認
- スマホのアプリでの見え方は未確認
