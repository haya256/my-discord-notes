# ボイスチャットを録音する(Craig)

> **注意**:この記事で扱う Craig は、Discordの公式機能ではありません。外部の開発者が提供するサードパーティのサービスです(公式サイト:https://craig.chat/)。紹介はしますが、推奨や保証はしません。

## 要点

- Discordには、通話をまるごと録音する標準の機能はないと思われる(未確認)。録音には外部のBotやソフトを使う
- 「Craig」は**Discordの公式機能ではなく、サードパーティ(外部の開発者)が提供する録音用Bot**。サーバーに追加して使う
- Craigを使うと、**話す人ごとに別々の音声ファイル**で録音できる。あとで編集しやすい
- **録音する前に、参加者全員の同意を取る**。Craigの公式FAQも、無断の録音は不道徳で違法だとしている

## 準備:Craigをサーバーに追加する(最初の1回だけ)

1. ブラウザで Craig の公式サイト(https://craig.chat/)を開く
2. 「Add to Discord」を押す
3. 追加先のサーバーを選び、権限を許可する

- サーバーにBotを追加できるのは、そのサーバーで権限を持っている人(管理者など)
- Craigが必要とする権限は「メッセージを送信」「接続」「ニックネームの変更」(公式ドキュメントより。画面の日本語表記は未確認)

## 手順:録音する

1. 録音したいボイスチャンネルに入る
2. テキストチャンネルで `/join` を実行する。Craigが同じボイスチャンネルに入り、録音が始まる
   - 別のチャンネルを録音したいときは、`/join` のあとにチャンネルを指定する
3. 録音を始めた人に、Craigから**ダウンロード用のリンクがDMで届く**
4. 終わったら `/stop` を実行する
5. DMのリンクから音声ファイルをダウンロードする

## 録音中のこと

- Craigのニックネームに「[RECORDING]」が付き、録音中だと参加者にわかる。ニックネームを変えられないと、Craigは録音しない
- `/note メモ` で、その時点にメモを残せる。メモはダウンロードした情報ファイルや、Audacityのプロジェクトに入る

## ダウンロードと保存期間

- 形式:FLAC、MPEG-4 AAC、Audacityのプロジェクト、Adobe Auditionのセッションなどから選べる
- 1回の録音は**最長6時間**(無料の場合)
- 録音は**7日間**保存される(無料の場合)。それまでにダウンロードする
- この制限は、話す人数、音質(ビットレート)、ほかのBotがいるかどうかに関係なく同じ

### 支援者(有料)プランの場合

Craigには月額の支援者プラン(Supporter)があり、録音時間と保存期間が延びる。

| プラン | 月額 | 1回の録音 | 保存期間 |
|---|---|---|---|
| 無料 | なし | 6時間 | 7日 |
| Tier 1 | $1 | 6時間 | 14日 |
| Tier 2 | $4 | 24時間 | 1か月 |
| Tier 3 | $8 | 24時間(Tier 2の特典を含む) | 1か月(同) |

- 支援者は `/bless` で1つのサーバーに特典を適用できる。そのサーバーでは、支援者でない人が始めた録音にも特典が付く
- 価格や内容は変わることがあるので、使う前に公式の支援者ページ(https://craig.chat/supporter)で確認する
- リンクをなくしたら `/recordings` で過去の録音を表示できる。他の人が始めた録音なら、リンクはその人のDMに届いているので、その人に頼む

## よく使うコマンド

| コマンド | やること |
|---|---|
| `/join` | 今いるボイスチャンネルで録音を始める |
| `/stop` | 録音を止める |
| `/note メモ` | 録音の今の時点にメモを残す |
| `/recordings` | 過去の録音とリンクを表示する |
| `/voice-test` | ボイスチャンネルで音質をテストする |

## メモ

- サードパーティのサービスなので、次の点に気をつける(一般的な注意。実機では未確認)
  - 録音データはCraigのサーバーに保存される(無料なら7日間)。会話の内容を外部に預けることになるので、参加者の同意を取るときにそのことも伝える
  - サービスの都合で止まったり、仕様が変わったりすることがある。大事な録音では、別の方法(OBSなど)も用意しておく
  - 追加は公式サイト(https://craig.chat/)から行う。似た名前の偽物のBotに注意する
  - 支援者プランはCraigのもので、DiscordのNitroとは別
- この記事はCraigの公式サイトの情報をまとめたもので、実機では未確認(2026-11-04時点)
- 管理者以外の人にも録音させたいときは、Craigの「アクセスロール」を設定する(設定には Manage Server〈サーバー管理〉の権限が必要。公式ドキュメントより。日本語の表記と手順は未確認)
- DMを受け取らない設定にしていると、リンクのDMが届かない。そのときは `/recordings` を使う
