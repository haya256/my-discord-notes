# イベント機能

## 要点

- **イベント**は、サーバーで行う予定(通話会、ゲーム会、勉強会など)を登録して、メンバーに知らせる機能
- メンバーは「**興味あり**」を押すだけ。押した人には、イベントが始まるころに通知が届く
- 「参加する/しない」の返事を集める機能はなく、**出欠をきっちり管理するのには向かない**。逆に、**サーバーの全員に向けて「よかったら来てね」と声をかける、ゆるい集まり**にちょうどよい

## イベントとは

サーバーの**共有カレンダー**に予定を書きこんで、気になる人だけが「行くかも」と印を付けておく、というイメージ。

- 予定を登録すると、チャンネル一覧のいちばん上に「〇件のイベント」のように表示される。サーバーのメンバーなら誰でも見られる
- 気になる人は「興味あり」を押す。押した人には、イベントが始まるころに通知が届くので、忘れにくい
- 主催者は、「興味あり」を押した人の数や顔ぶれを見られる。「何人くらい来そうか」の目安になる
- 「興味あり」を押していなくても参加できるし、押したのに来なくても誰も困らない

### 向いている使い方・向いていない使い方

| 向いている | 向いていない |
|---|---|
| 毎週の雑談通話会、もくもく会(各自が作業する会) | 人数分の席や食事を用意する集まり(正確な人数が要る) |
| 「今夜みんなでゲームしませんか」という声かけ | 参加・不参加を全員から必ず返事してほしい会 |
| 誰でも聞きに来られる発表会・勉強会 | 参加費を集める会、参加者を締め切る会 |
| 現実の集まりの「お知らせ」(場所の案内だけ) | 特定の人だけに知らせたい会(イベントはサーバーの全員に見える) |

- 出欠をきっちり取りたいときは、イベントとは別に、チャンネルでアンケート(投票)を取ったり、外部の出欠管理サービスを使ったりする

## 開催場所の種類

イベントを作るとき、開催場所を3種類から選ぶ。

| 場所 | 向いているもの |
|---|---|
| ボイスチャンネル | 通話会、ゲーム会など、みんなで話す集まり |
| ステージチャンネル | 発表会、講演、質問会など、話す人と聞く人が分かれる集まり |
| 外部の場所(英語版は Somewhere Else) | 別のサービスでの配信、現実の会場など。URLや住所を書く |

## 手順(PC)

### イベントを作る

1. サーバー名の横の下矢印を押して、メニューから「イベントを作成」を選ぶ
2. 開催場所(ボイスチャンネル/ステージチャンネル/外部の場所)を選ぶ。ボイスやステージなら、使うチャンネルも選ぶ
3. イベントの名前、開始日時、説明を書く。必要なら表紙の画像を付ける(外部の場所のときは、終了日時も必要)
4. 内容を確認して公開する

- 「イベントを作成」は公式ヘルプ(日本語版)の表記。ほかの画面の名前は未確認

### イベントに「興味あり」を付ける

1. チャンネル一覧のいちばん上の「〇件のイベント」を押す
2. 気になるイベントの「興味あり」を押す

### イベントを始める・終える

- ボイスチャンネルやステージチャンネルのイベントは、開始時刻になったら主催者が「開始」の操作をする(と言われている)。始まると「興味あり」の人に通知が届く
- 終わったら終了する

## 作れる人(権限)

イベントの権限はロールで決める([13-roles.md](13-roles.md) を参照)。公式ヘルプによると、権限は2種類ある。

| 権限 | できること |
|---|---|
| イベントの作成 | イベントを作る。編集・キャンセルできるのは、**自分が作ったイベントだけ** |
| イベントの管理 | **すべてのイベント**を編集・キャンセルできる |

- 設定の場所:「サーバー設定」→「ロール」→ ロールを選ぶ →「権限」の、サーバー全般の権限の中
- メンバーの誰でもイベントを作れるようにするなら、メンバー用のロール(または @everyone)に「イベントの作成」を付ける。運営だけが作るなら、運営のロールにだけ付ける

## 「〇件のイベント」の未読の点

新しいイベントが増えると、チャンネル一覧のいちばん上の「〇件のイベント」に**未読の点**が付く。ところが、開いて一覧を見ても、**どのイベントが新しく増えたのかは分からない**。

- 実機での例:未読の点が付いたので開いてみると、11件のイベントが並んでいた。どれが新しいのか、印も並び順の手がかりもなかった
- 一覧の中で、新しいイベントに「新着」のような印を付ける機能は、見つけられなかった。Discord公式フォーラムに「新しく増えたイベントを一覧で見分けられるようにしてほしい」「新しいイベントの印がほしい」という要望が出ている(実装されたかは未確認)
- 同じ要望の中に「いつも数十件のイベントがあるサーバーでは、スクロールして新しいものを探すのは無理」という声もある

### 未読の点を消す・付かないようにする(PC)

「〇件のイベント」のメニューに、次の2つがある(実機で確認。メニューは右クリックで出ると思われるが、出し方は未確認)。

| メニュー | すること |
|---|---|
| 既読にする | 今付いている未読の点を消す |
| 新しいイベントをミュート | チェックを入れると、新しいイベントが増えても未読の点が付かなくなる(と思われる) |

- イベントの未読の点がわずらわしいときは「新しいイベントをミュート」にチェックを入れる
- ミュートしても、「興味あり」を押したイベントの通知が止まるかどうかは未確認
- スマホでの操作は未確認

### 運営の側でできる工夫

- イベントを作ったら、お知らせ用のチャンネルにも「〇〇のイベントを追加しました」と書く。そうすれば、メンバーはどれが新しいか分かる
- 終わったイベント・やらなくなったイベントは、こまめにキャンセルして、一覧を短く保つ
- 先の予定をたくさん並べすぎない(下の「メモ」の、数週間以内の予定に使うという助言も参照)
