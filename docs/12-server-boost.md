# サーバーブースト

## 要点

- **サーバーブースト**は、好きなサーバーにお金を払って「ブースト」を付け、そのサーバーの機能を強化するしくみ。ブーストした本人だけでなく、**サーバーのメンバー全員**が特典を受けられる
- ブーストの数が増えると、サーバーの**レベル**が上がる(2個でレベル1、7個でレベル2、14個でレベル3)。レベルが上がると、絵文字の枠、音質、アップロード上限などが増える
- 2026年からは、ブーストをレベルに使わず、「サーバータグ」などの**追加特典**に直接使うこともできる
- Nitro(Basicではない方)に入っていると、**毎月ブースト2個**が付いてくる(`08-nitro.md` を参照)
- ブーストは**サブスク(月額の契約)**。解約するまで毎月自動で続き、**解約すると外れる**。回数が積み上がっていくものではない

## ブーストはサブスク

ブーストのしくみで分かりにくいところなので、整理しておく。

- ブーストは「1回使うと1か月効くチケット」**ではない**。動画配信サービスの月額会員と同じ、**サブスク(月額の契約)**
- 一度ブーストすると、**解約しないかぎり毎月自動で更新されて、ずっとそのサーバーに付いたまま**になる。1か月たっても勝手には消えない
- ブーストが外れるのは、次のようなとき
  - 本人がブーストを解約したとき(払い済みの期間が終わったところで外れるとされる)
  - 支払いができなかったとき
  - Nitroを解約したとき(Nitroに付いてくる2個の場合)
- **累積はしない**。サーバーのブースト数は「これまでに付いた回数の合計」ではなく、「**いま契約が続いているブーストの数**」
  - 例:5人が1個ずつブーストを続けていれば、何か月たっても5個のまま。そのうち2人が解約すれば、3個に減る
- ブーストが減ってレベルの条件を下回ると、特典が使えなくなる(猶予などは下の「ブーストが減ったとき」を参照)
- 付けたブーストは、契約を続けたまま別のサーバーに移せる(下の「ブーストを別のサーバーに移す」を参照)

- この節の「解約すると外れる」「払い済みの期間が終わったところで外れる」などは一般的な知識で、公式の情報や実機では確認していない

## レベルと必要なブースト数

| レベル | 必要なブースト数 |
|---|---|
| なし | 0〜1 |
| レベル1 | 2 |
| レベル2 | 7 |
| レベル3 | 14 |

- 以前は、レベル2に15個、レベル3に30個が必要だった。ネット上の古い記事には古い数字が書かれていることがある

## レベルごとの主な特典

上のレベルは、下のレベルの特典もすべて含む。数字は合計。

| 特典 | レベル1 | レベル2 | レベル3 |
|---|---|---|---|
| カスタム絵文字の枠 | 100 | 150 | 250 |
| スタンプの枠 | 15 | 30 | 60 |
| サウンドボードの枠 | 24 | 36 | 48 |
| ボイスチャンネルの音質 | 128kbps | 256kbps | 384kbps |
| 画面共有・配信(Go Live)の画質 | 720p 60fps | 1080p 60fps | 1080p 60fps |
| メンバー全員のアップロード上限 | 変わらない | 50MB | 100MB |
| 見た目 | アニメーションするサーバーアイコン、招待の背景 | サーバーバナー、ロールアイコン | アニメーションするバナー、カスタム招待リンク |

- **カスタム招待リンク**は、`discord.gg/好きな名前` のような覚えやすい招待リンクを作れる機能(バニティURLとも呼ばれる)
- 資料によって、どのレベルに入っている特典かが少し違う(招待の背景、レベル1の配信画質など)。細かい数字は公式の情報で確認する
- アップロード上限は、ブーストした人だけでなくサーバーのメンバー全員に効く。ただし、そのサーバーに送るときだけ(無料ユーザーのふだんの上限は `03-files.md` を参照)

## 追加特典(2026年から)

ブーストを、レベルを上げるためではなく、次の特典に直接使える。

| 追加特典 | 必要なブースト数 | 内容 |
|---|---|---|
| サーバータグ | 3 | 4文字までのタグを、メンバーのプロフィールの名前の横に表示できる |
| ロールの特別な色 | 3 | ロールの色を、グラデーションやホログラムのように動く色にできる |
| 大きいファイルのアップロード | 5 | メンバー全員の上限を250MBにする。試験中で、使えない場合がある |
| ゲームサーバーのホスティング | 3以上 | ゲームや規模によって変わる |

- **1個のブーストは、レベルか追加特典のどちらか一方にしか使えない**。たとえばブーストが10個あれば、7個でレベル2にして、残りの3個でサーバータグを使える
- 追加特典の設定は、今のところPC版でだけできるという情報がある
- 資料によって、ほかにも追加特典が載っている(サーバーのテーマなど)。種類や必要な数は変わりやすい

## 料金

- 1ブーストあたり月額 **$4.99**(米ドル)という情報がある。Nitroに入っていると、追加のブーストが**30%引き**になる
- Nitro(Basicではない方)には、毎月2個のブーストが付いてくる。Nitro Basicには付かない
- 日本円での価格は未確認。アプリの中で確認する

### Nitroに入ったら、ブーストは使わないともったいない

| やり方 | 月額(米ドル) | 付いてくるもの |
|---|---|---|
| ブーストだけを2個買う | $4.99 × 2 = $9.98 | ブースト2個 |
| Nitroに入る | $9.99 | ブースト2個 + Nitroの特典すべて |
| ブーストだけを3個買う | $4.99 × 3 = $14.97 | ブースト3個 |
| Nitroに入って1個を追加で買う | $9.99 + $3.49 = $13.48 | ブースト3個 + Nitroの特典すべて |

- Nitroの月額には、**ブースト2個分(単品で買うと$9.98)の値段がほぼそのまま入っている**と考えられる
- なので、Nitroに入っているのにブーストを使っていないのは**もったいない**。どこかのサーバー(自分のサーバーでもよい)に付けておくだけで、2個でレベル1の特典が使える
- ブーストを使う予定がなく、ほかの特典(1GBのアップロード、HD配信など)も要らないなら、安いNitro Basicで足りないか考える
- 逆に、ブーストを2個以上したいなら、ブーストだけを買うよりNitroに入る方が得
- 値段は米ドルでの比較。$4.99・$3.49 は非公式の情報で、日本円では差が変わるかもしれない

## 手順(PC)

### サーバーをブーストする

1. ブーストしたいサーバーで、サーバー名を押してメニューを開く
2. 「サーバーブースト」の項目を選ぶ
3. 画面の案内に従って、ブーストする(Nitroに付いてくるブーストがあれば、それを使える)

### ブーストを別のサーバーに移す

1. 左下の歯車「ユーザー設定」を開く
2. 左メニューの「サーバーブースト」を開く
3. 移したいブーストを選び、別のサーバーに移す

- ブーストしてから**7日間**は、別のサーバーに移せない

- 日本語版の画面での名前は未確認です

## ブーストが減ったとき

- **レベルの特典**:ブーストが足りなくなっても、**72時間**は猶予がある。そのあいだに数が戻らなければ、特典は使えなくなる。レベルの条件を満たせば、また使えるようになる
- **カスタム招待リンク**:すぐに使えなくなる。30日たつと、その名前をほかのサーバーが使えるようになる
- **追加特典**:猶予はなく、必要な数を下回るとすぐに使えなくなる
