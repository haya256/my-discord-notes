# コミュニティ機能

## 要点

- **コミュニティ機能**は、サーバーを「大人数で運営するコミュニティ向け」に切り替えるDiscord本体の設定。オンにすると、運営に便利な機能が使えるようになる
- そのかわり、**安全のための設定を必ずオンにする**必要がある(メール認証、メディアのスキャン、ルールチャンネルなど)
- 仲間内の小さなサーバーなら、無理にオンにしなくてよい。お知らせのフォローやAutoModのスパム対策などを使いたいときにオンにする
- **オンにしただけでは、サーバーは公開されない**。入り方は今までと同じで、招待リンクを知っている人だけが入れる

## 「コミュニティ」という言葉の意味

ここはまぎらわしいので、整理しておく。

- ふだんの言葉の「コミュニティ」(人が集まる場所)なら、**コミュニティ機能をオンにしていないサーバーでも、十分にコミュニティとして使える**。サーバーを作った時点で、仲間を集めて話す場所になっている
- Discordが設定の名前として使う「コミュニティ」は、それより狭い意味。オンにしていないふつうのサーバーは、**小規模な仲間内**で使うことを想定している。人数が大きくなってきたときや、**知らない人も含めて広く参加を受け付けたい**ときのための状態を、Discordは「コミュニティ」と呼んでいる
- だからオンにすると、知らない人が大勢入ってくることへの備え(メール認証、画像などのスキャン、ルールチャンネル)が必須になる。あわせて、大人数を運営するための道具(アナウンスチャンネル、オンボーディング、統計など)が使えるようになる
- ただし、オンにすること自体は「公開する準備ができた状態」になるだけ。実際に誰でも入れるようにするかどうかは、次の2つで決まる
  - 招待リンクをどこまで広く公開するか
  - サーバー発見(Discovery)に載せるか(人数などの条件あり)
- 逆に、外には閉じたまま大人数で使うサーバー(ファンクラブや会員向けなど)が、運営の道具を使いたくてオンにすることもある

| | コミュニティ機能オフ(ふつうのサーバー) | コミュニティ機能オン |
|---|---|---|
| 想定している使い方 | 小規模な仲間内 | 大人数、または広く参加を受け付ける |
| 安全のための設定 | 自由(設定しなくてもよい) | メール認証・メディアのスキャン・ルールチャンネルなどが必須 |
| 運営の道具 | 基本的な機能のみ | アナウンスチャンネル・オンボーディング・サーバーインサイトなど |
| 入り方 | 招待リンク | 招待リンク(条件を満たせばサーバー発見にも載せられる) |

## オンにする条件

オンにする途中で、次の設定を求められる。

| 条件 | 内容 |
|---|---|
| 認証レベル | メールアドレスを認証したアカウントでないと、メッセージやDMを送れないようにする。ロールが付いているメンバーは対象外 |
| 不適切なメディアのフィルター | すべてのメンバーが送った画像などをスキャンし、不適切と判定されたものを消す。年齢制限のあるチャンネルは対象外 |
| ルールチャンネル | 新しいメンバーに、サーバーのルールを見せるチャンネル。なければDiscordに作ってもらえる |
| コミュニティアップデートチャンネル | Discordから管理者向けのお知らせが届くチャンネル。モデレーターだけが見られるようにする。これもDiscordに作ってもらえる |
| ガイドラインへの同意 | Discordのコミュニティガイドラインを守ることに同意する |

- 認証レベルを「低・中・高」のどこまで上げる必要があるかは、資料によって書き方が違う。この記事では「メール認証済みが必要」とだけ書いておく

## オンにするとできること

| 機能 | 内容 |
|---|---|
| アナウンスチャンネル | お知らせ用のチャンネル。ほかのサーバーが「フォロー」すると、投稿がそのサーバーにも届く |
| サーバーインサイト | 参加者の定着率や、発言する人と見ているだけの人の割合などの統計を見られる。ある程度の人数(500人ほどという情報あり)にならないと使えない |
| オンボーディング | 新しく入った人が、質問に答えてロールやチャンネルを選べる仕組み。以前の「ウェルカムスクリーン」に代わるもの |
| サーバー発見(Discovery) | Discordの「発見」ページにサーバーを載せられる。ただし、メンバーが1,000人を超えている、または公認・認証済みのサーバーなどの条件がある |
| AutoModのスパム対策 | スパムのブロックや、メンションスパムのブロックが使える([10-raid-protection.md](10-raid-protection.md) を参照) |
| Discordからのお知らせ | 運営に関わる仕様変更などのお知らせが、コミュニティアップデートチャンネルに届く |

## 「発見対象」の表示(チャンネルの内容がウェブに出る)

チャンネル名の横に「**発見対象**」と出ていて、チャンネルの上に「**このチャンネルのメッセージ内容は、ウェブページに表示される場合があります。**」と出ていることがある(実機で確認)。

これは、**そのサーバーがサーバー発見に載っていて、そのチャンネルの内容が Discord の外のウェブページに出るかもしれない**という知らせ。書きこむ前に分かるように、対象のチャンネルにこの表示が付く。

### 何が、いつからウェブに出るのか

2026年10月27日の公式ブログで発表された。

| 名前 | 内容 | 始まり |
|---|---|---|
| サーバーのウェブページ(Server Web Page) | サーバー発見に載っているサーバーごとに、サーバーを紹介するウェブページができる。管理者が作らなくても、サーバープロフィールの内容から自動で作られる | 2026年11月16日 |
| チャンネルの要約(Channel Summaries) | サーバーの中で話されていることを、短くまとめてウェブページに出す。自動で作られる | 2026年11月16日 |
| チャンネルのメッセージ(Channel Messages) | 公開チャンネルで、質問への答えなどのメッセージが、**書いた人の言葉のまま**ウェブページや**検索結果**に出る | 2026年12月中旬から少しずつ。それより前に送ったメッセージは出ない |

- 対象は、**サーバー発見に載っているサーバー**の、**公開チャンネル**(サーバーの全員が見られるチャンネル)だけ。非公開のチャンネル、ふつうのサーバー、DM、グループDMは対象外
- ウェブページには、**ユーザー名とアバターは出ない**(要約にもメッセージにも)
- 検索エンジンで見つかることを想定している

### 自分のメッセージを出さないようにする(メンバーができること)

1. 「ユーザー設定」(左下の歯車)を開く
2. 左メニューの「データ&プライバシー」を開く
3. 「**発見対象チャンネルの私のメッセージ内容をウェブページに表示**」のスイッチをオフにする(英語版は「Show my message content from Discoverable channels on web pages」)

- 画面の説明には「これらのメッセージは入力したとおりに表示されますが、ユーザー名は表示されません」とある(実機で確認)
- スイッチは1つで、**すべてのサーバーに効く**
- 初めの状態はオン。ただし、EU・イギリス・カナダ・ブラジル・オーストラリア・韓国ではオフ。日本では**オンになっていた**(実機で確認、2026-11-21)
- 10代のユーザーは対象外(大人になるまでオンにできない)
- オフにしても、**オンだった間に送ったメッセージは消えない**。出したくなければ、そのメッセージを消す
- このスイッチは**チャンネルの要約には効かない**。要約は管理者が止めないかぎり出る

### 管理者ができること

- 「サーバー設定」→「Web Presence」(日本語版の名前は未確認)で、ウェブに出すチャンネルを選んだり、すべてオフにしたりできる
- チャンネルの要約も、元にするチャンネルを変えたり、出す要約を選んだり、オフにしたりできる
- 何もしなければ、**公開チャンネルはすべて対象のまま**になる
- サーバーのウェブページそのものをなくす設定はないという報道がある(未確認)。サーバー発見から外せば対象ではなくなる

## 手順(PC)

### オンにする

1. サーバーのオーナー(または十分な権限があるアカウント)で、サーバー名を押して「サーバー設定」を開く
2. 左メニューの、コミュニティを有効にする項目(英語版は「Enable Community」)を開く
3. 「はじめる」(英語版は「Get Started」)を押す
4. 画面の案内に従って、上の「オンにする条件」の設定をする
5. ガイドラインに同意して、設定を完了する(英語版は「Finish Setup」)

### オフにする

1. 「サーバー設定」を開く
2. 左メニューのコミュニティの項目の中にある「概要」(英語版は「Overview」)を開く
3. いちばん下の、コミュニティを無効にするボタン(英語版は「Disable Community」)を押す

- 日本語版の画面での名前は未確認です。上の手順のかっこ内は英語版の名前

## メモ

- この記事はほとんどネットの情報でまとめた。実機で確認したのは「発見対象」のラベル、チャンネルの上の案内の文、「データ&プライバシー」のスイッチの名前と初めの状態だけ。ほかは**実機では確認していない**
- オンにすると、メール認証をしていない人や、ロールのない新しい人が発言できなくなる場合がある。オンにした直後に「書き込めない」と言われたら、まず認証レベルを疑う
- サーバー発見に載せると、公開チャンネルの内容の一部がウェブ上に表示される場合がある。載せたくないチャンネルは、サーバー設定で外せる(公式ヘルプの日本語ページの内容から)。くわしくは上の「「発見対象」の表示」
- サーバーインサイトやサーバー発見の人数条件は、変わることがある。使う前に公式ヘルプで確認する
